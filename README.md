# 🎙️ Харви — локальная голосовая помощница для Windows

**Говорите «Харви, …» — и компьютер делает. Без облака, без подписок, всё работает на вашем ПК.**

> **EN:** Harvey is a fully offline, Russian-speaking voice assistant for Windows 11. It listens for its
> name, transcribes speech with faster-whisper, executes ~50 system actions (apps, media players, volume,
> windows, timers, reminders, calculations…) through a fast rule-based parser, and falls back to a local LLM
> (Ollama, Gemma) with tool calling only for phrases the rules don't understand. Replies are spoken with
> Silero / Piper TTS. Nothing leaves the machine.

## Что умеет

| | Примеры фраз |
|---|---|
| 🚀 **Приложения и сайты** | «открой телеграм», «закрой браузер и яндекс музыку», «ютуб котики», «найди рецепт борща» |
| 🎵 **Медиа** | «музыка стоп», «ютуб на паузу», «следующий трек», «что играет», «сними с паузы» |
| 🔊 **Звук и экран** | «громкость 30», «музыку тише», «телеграм на 50», «ярче», «выключи звук» |
| 🪟 **Окна и клавиши** | «сверни всё», «переключи окно», «закрой вкладку», «сделай скриншот», «заблокируй компьютер» |
| ⏰ **Время и дела** | «таймер на 5 минут», «напомни в 18:00 позвонить маме», «запиши: купить хлеб», «какое сегодня число» |
| 🌦️ **Справки** | «какая погода», «курс доллара», «сколько будет 15% от 2 400», «загрузка процессора» |
| ⌨️ **Диктовка** | «запиши …» — текст печатается в активное окно, ИИ расставляет знаки препинания |
| 🧠 **ИИ** | «что такое квантовая запутанность», «переведи выделенное», «перепиши вежливее», «что на экране» |
| ⚡ **Питание** | «выключи компьютер» → «Вы уверены?» → «да» (с задержкой, можно отменить голосом) |

Можно соединять команды: «громкость 30 и пауза». После ответа Харви несколько секунд слушает
продолжение без имени (режим диалога).

## Как это устроено

```
 Микрофон ──► VAD ──► имя «Харви»? ──► faster-whisper ──► исправление ослышек
                    (openWakeWord / Whisper)                       │
                                                                   ▼
                                     ┌──────────── parse_all: регулярки, ~1 мс ────────────┐
                                     │  понято?  ── да ──► tools.execute_tool(...)          │
                                     │     │                                                │
                                     │    нет ──► Ollama (Gemma) + tool calling, 1 запрос   │
                                     └──────────────────────────────────────────────────────┘
                                                                   │
                                     Silero / Piper ◄── ответ (или только звук «готово»)
```

Ключевые решения:

- **Быстрый путь без ИИ.** Большинство команд разбирается регулярками из `phrases.py` за миллисекунды.
  К языковой модели уходит только то, что правила не поняли, и ровно один запрос: ответ собирает код,
  а не второй проход модели.
- **Один путь для действий.** И правила, и ИИ выполняют действия только через `tools.execute_tool` —
  он логирует результат и ловит исключения. Поэтому тесты могут подменить именно его и проверить,
  какое действие *было бы* выполнено.
- **Тихий режим.** После обычного действия звучит лишь короткий сигнал; вслух — только то, что нужно
  услышать (время, погода, ошибка, вопрос). Музыка приглушается, пока Харви говорит.
- **Управление конкретными плеерами** через Windows SMTC: «ютуб стоп» ставит на паузу именно браузер,
  а не Spotify. WinRT вызывается из отдельного MTA-потока с собственным циклом asyncio.
- **Цикл улучшений по логу.** `log_report.py` показывает фразы, ушедшие в ИИ, ошибки и задержки,
  а также заново прогоняет фразы из лога через текущие правила — так видно и прогресс, и регрессии.

## Установка

Нужны **Windows 10/11**, **Python 3.11** и [Ollama](https://ollama.com). Видеокарта NVIDIA (CUDA 12)
желательна: на ней Whisper `large-v3-turbo` распознаёт фразу за доли секунды; без неё используется
модель поменьше на процессоре.

```bash
git clone https://github.com/kiberbus/Harvey_AI_assistant.git
cd Harvey_AI_assistant
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
ollama pull gemma4:e4b
.venv\Scripts\python harvey.py
```

Модели Whisper и голоса (Silero / Piper) скачиваются сами при первом запуске. После старта у часов
появится значок в трее: сон, перезапуск, автозапуск, отчёт по логу, выход.

## Настройка

Все настройки — в [`config.py`](config.py), с комментариями:

- имя, голос и род ответов («открыла» / «открыл»), обращение («господин», «сэр» или без него);
- модель Ollama, модель Whisper, устройство (`cuda` / `cpu`);
- город для погоды, домашняя валюта, сайты и папки;
- `NAME_GROUPS` — как можно назвать приложение голосом и какие у него процессы;
- тихий режим, режим диалога, подтверждение опасных команд.

Формулировки команд и типичные ослышки Whisper — в [`phrases.py`](phrases.py).
Своё слово-активатор можно обучить по инструкции в [`wake/КАК ОБУЧИТЬ.txt`](wake/КАК%20ОБУЧИТЬ.txt).

## Структура

```
harvey.py        главный цикл: микрофон → имя → распознавание → команда; диалог, «да/нет», сон
config.py        все настройки
phrases.py       формулировки команд (регулярки) и исправления ослышек
log_report.py    отчёт по логу: что ушло в ИИ, ошибки, задержки, регрессии
core/
  parse.py       быстрый разбор фраз без ИИ
  commands.py    маршрутизация: заметки/диктовка → правила → ИИ
  tools.py       реестр действий и их описания для tool calling
  llm.py smart.py      Ollama: команды, вопросы, текст и снимок экрана
  stt.py speech.py     Whisper, VAD, openWakeWord; синтез речи и сигналы
  apps.py media.py audio.py system.py daily.py calc.py   сами действия
  winapi.py uia.py tray.py                               ctypes, UI Automation, трей
tests/           348 тестов, < 1 с; без микрофона, моделей и PowerShell
```

## Тесты

```bash
.venv\Scripts\python -m pytest -q
```

`tests/test_phrases.py` — 150 пар «фраза → ожидаемые вызовы». Каждая неудача из реальной жизни
(«сними с паузы» не должно стать паузой, «включи звук» — медиа) закрепляется тестом.

## Приватность

Распознавание, синтез и языковая модель работают локально. В сеть Харви обращается только за тем,
что вы явно спросили (погода через Open-Meteo, курс валют), и за моделями при первом запуске.
Лог с распознанной речью хранится только на вашем компьютере и отключается настройкой `LOG_ENABLED`.
